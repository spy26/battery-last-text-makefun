One line of plain text (135 characters) for make.fun's "The Battery's Last Text to Its Charger" — the whole entry, in `entry.txt`: the phone battery's final text to the charger it waited for all day. The twist is revenge, not a farewell: the battery is taking the owner's forgotten 3am password to the grave with it, and the last words are a parting shot — "tell them i said good luck."

## Run it

```sh
python3 main.py
```

`main.py` reads `entry.txt`, validates the line (exactly one line, 1–200 characters, not only whitespace), prints it verbatim to stdout, and writes it to `/output/entry.txt` for the grader. Deterministic: the same line, byte-identical, on every run. No network, no randomness, no reads outside this repository.
